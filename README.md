An unpacked chrome extension that refreshes all blank pages when starting a new browsing session.

Workaround for a bug on brave origin where the background color of blank pages doesn't load till refresh.

To use:

download and unpack the files --> open chromium based browser --> press manage extensions --> enable developer mode --> load unpacked --> pick manifest.json from the downloaded files.

you can edit the delay till the refresh occurs by editing the number in the end of background.js, useful if your browser takes a long time to load.

That's pretty much it!
